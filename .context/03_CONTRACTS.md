## Rules
- Enums: `violation.type` in {RED_LIGHT_JUMP, OVER_SPEED, NO_HELMET, WRONG_WAY} (only RED_LIGHT_JUMP active in Phase 0).
  `script_type` in {DEVNAGARI_ZONAL, DEVNAGARI_PROVINCIAL, ENGLISH, UNKNOWN}.
- `speed` fields are null in Phase 0. Speed is "indicative only" until radar-certified (Phase 4).
- Signature is computed over canonical JSON (sorted keys, no whitespace, UTF-8) excluding `manifest_signature` itself.
- Strict validation: reject unknown fields, enforce length limits, validate ranges (lat/lng, confidence 0-1).
- Plate text is untrusted: validate with format regex, escape wherever rendered (HTML, PDF, SMS).
- Server filenames are generated by the server (UUID); client filenames are labels only.
- Idempotency key: `event_id`. Duplicate => 200 with existing record, no new ticket.

## API surface (Phase 0 draft; refine via ADR)
- `POST /v1/ingest/events` (mTLS device) multipart: manifest JSON + media files
- `GET  /v1/review/queue` (officer) paginated, jurisdiction-scoped
- `GET  /v1/events/{id}` (officer) with presigned media URLs (short-lived)
- `POST /v1/events/{id}/approve` | `/reject` (officer; edits to plate require second-officer approval)
- `GET  /v1/challans/{id}.pdf`
- `GET  /v1/devices` health
- `POST /v1/auth/login`, `/v1/auth/mfa`, `/v1/auth/refresh`
